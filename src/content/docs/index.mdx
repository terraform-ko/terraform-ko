# Terraform 문서

Terraform은 코드로 인프라를 안전하고 효율적으로 구성·변경·버전 관리할 수 있게 해주는 인프라 as 코드(IaC) 도구입니다. 컴퓨트 인스턴스, 스토리지, 네트워킹 같은 저수준 구성 요소부터 DNS, SaaS 기능 같은 고수준 구성 요소까지 다룰 수 있습니다.
