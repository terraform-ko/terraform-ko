# Terraform CLI 문서

> **실습:** [Terraform: Get Started](https://developer.hashicorp.com/terraform/tutorials/aws-get-started) 튜토리얼을 진행해보세요.

이 문서는 Terraform CLI 명령어에 대한 레퍼런스 정보와, 명령어를 사용해 인프라를 프로비저닝하고 인프라 라이프사이클을 관리하는 방법을 다룹니다. Terraform CLI를 단독으로 사용하는 사람뿐 아니라, HCP Terraform이나 Terraform Enterprise와 함께 Terraform CLI를 사용하는 사람 모두에게 유용합니다.

Terraform 구성 언어(configuration language)의 문법과 작성 패턴에 대한 정보는 [Terraform 구성 언어 문서](https://developer.hashicorp.com/terraform/language)를 참고하세요. (아직 번역되지 않았습니다)
